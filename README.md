# 📱 Телефонға арналған веб-терминал

Бұл — браузерден ашылатын нағыз Linux терминал. Ішінде Codex CLI, Claude Code CLI немесе кез келген құралды орната аласың. Компьютер керек емес — барлығын осы телефоннан жасайсың.

⚠️ **МАҢЫЗДЫ:** Бұл терминал сенің телефоныңа немесе жоқ компьютеріңе қосылмайды. Ол Render-дегі бөлек, кішкентай **бұлттық Linux контейнерге** кіру есігі. Сол контейнердің ішінде Codex/Claude Code жұмыс істейді, файлдар сақталады (тегін тарифте контейнер қайта іске қосылса, файлдар өшуі мүмкін — төменде ескерту бар).

---

## 1-қадам: GitHub-қа репозиторий жасау (телефон браузерінен)

1. [github.com](https://github.com) сайтына кіріп, аккаунт аш (жоқ болса).
2. Жоғарғы оң жақтағы **+** белгісін бас → **New repository**.
3. Атын жаз, мысалы `phone-terminal` → **Create repository**.
4. Репозиторий ішінде **Add file → Upload files** түймесін бас.
5. Мына 5 файлды бір-бірлеп жүкте (әр файлды "Create new file" арқылы да жасауға болады, атын дәл жаз):
   - `server.js`
   - `package.json`
   - `Dockerfile`
   - `render.yaml`
   - `public/index.html` (папка атын `public/index.html` деп толық жазсаң, GitHub автоматты түрде `public` папкасын жасайды)
6. **Commit changes** бас.

## 2-қадам: Render-ге қосу

1. [render.com](https://render.com) сайтына кіріп, GitHub аккаунтыңмен тіркел.
2. **New +** → **Web Service** бас.
3. Жаңа ғана жасаған `phone-terminal` репозиторийіңді таңда.
4. Render `Dockerfile`-ды автоматты танып, **Environment: Docker** деп қояды (өзгертпе).
5. **Instance Type: Free** таңда.
6. **Environment Variables** бөлімінде қос:
   - Key: `TERMINAL_PASSWORD`
   - Value: өзіңнің күшті құпия сөзің (мысалы `MyStr0ng!Pass2026`)
7. **Create Web Service** бас.
8. 3-5 минут күт — Render Dockerfile-ды құрастырып, серверді іске қосады.

## 3-қадам: Ашу

Деплой аяқталған соң, жоғарыда `https://phone-terminal-xxxx.onrender.com` секілді сілтеме шығады. Соны телефонда ашсаң:
- Құпия сөзді енгіз → терминал ашылады
- Кез келген Linux командасын жаза бересің

## 4-қадам: Ішінде Codex/Claude Code орнату

Терминал ашылған соң, сол жерге теріп жібер:

```bash
# Claude Code орнату
curl -fsSL https://claude.ai/install.sh | bash
claude

# немесе Codex CLI (OpenAI) орнату (npm арқылы)
npm install -g @openai/codex
codex
```

## ⚠️ Ескертулер

- **Тегін Render тарифі** белсенді болмаса (15 мин пайдаланылмаса) контейнерді "ұйықтатады". Қайта ашқанда 30-50 секунд күтуің керек болады — бұл қалыпты.
- Тегін тарифте **диск тұрақты емес** — контейнер қайта іске қосылса (redeploy, ұйықтаудан оянғанда), ішіндегі файлдар өшуі мүмкін. Маңызды жұмысты git-ке commit жасап отыр, немесе Render-нің ақылы "Persistent Disk" опциясын қос.
- Бұл терминал арқылы кез келген адам (URL + құпия сөзді білсе) серверіңе толық қол жеткізе алады — **құпия сөзді ешкіммен бөліспе**, күрделі сөз қой.
- Егер тұрақты жұмыс керек болса (ұйықтамайтын, диск сақталатын), Render-нің ақылы жоспарына ($7/ай-дан) көшкен жөн.
